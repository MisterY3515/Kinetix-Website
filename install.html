Install Kinetix

Get started with Kinetix on your platform of choice.

⚠️

Kinetix is in active Pre-Release development. Prebuilt installers are published on GitHub Releases for Windows, Linux, and macOS (x86_64 and ARM64), but the exact set of assets attached to a given release can lag behind the latest source — if a download button below can't find a matching asset yet, it falls back to the Releases page. Building from source (instructions nested under each platform) always reflects the latest code.

🪟 Windows Recommended

The easiest way to install Kinetix. Download the installer for your CPU architecture from the latest GitHub Release and run it.

  1. Download the installer for your architecture below.
  2. Run the installer. It will guide you through the setup process.
  3. Once installed, open a terminal and verify with:
kivm version

Build from source instead

Requires the Rust toolchain (MSVC target) and the MSVC C++ build tools.

  1. Install Rust and the MSVC C++ build tools:
# Installs rustup (choose the default MSVC toolchain when prompted) # https://rustup.rs # Also install "Desktop development with C++" from the # Visual Studio Build Tools installer (provides the MSVC linker): # https://visualstudio.microsoft.com/visual-cpp-build-tools/ # -- for ARM64 builds, additionally add the "MSVC v143 - VS 2022 # C++ ARM64 build tools" individual component.
  1. Clone and build (produces kivm.exe / kicomp.exe):
git clone https://github.com/MisterY3515/Kinetix.git cd Kinetix cargo build --release -p kinetix-cli -p kinetix-kicomp .\target\release\kivm.exe version

To also build the GUI installer itself (-p kinetix-installer), no extra system packages are needed beyond the C++ build tools above.

Build Prerequisites

OS
Windows 10+ (x86_64 or ARM64)
Toolchain
Rust 1.85+ (stable, MSVC), VS C++ Build Tools
🐧 Linux Recommended

Download the prebuilt binary for your CPU architecture. It's a single standalone executable — no system package installation needed to run it.

  1. Download the installer for your architecture below.
  2. Make it executable and run it. It will guide you through the setup process.
  3. Once installed, open a new terminal and verify with:
chmod +x KinetixInstaller-linux-* ./KinetixInstaller-linux-*
kivm version

Build from source instead

Only the Rust toolchain is required to build kivm/kicomp — LLVM is not a build dependency of the default build.

  1. Install prerequisites:
# Debian / Ubuntu sudo apt update && sudo apt install -y build-essential curl curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh # Fedora / RHEL sudo dnf install -y gcc curl curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  1. Clone and build (produces kivm / kicomp):
git clone https://github.com/MisterY3515/Kinetix.git cd Kinetix cargo build --release -p kinetix-cli -p kinetix-kicomp sudo cp target/release/kivm /usr/local/bin/ kivm version

Building the GUI installer too (-p kinetix-installer, or a plain cargo build --release with no -p filter) additionally needs GTK3, ALSA, and X11/OpenGL headers:

# Debian / Ubuntu sudo apt install -y pkg-config libasound2-dev libgtk-3-dev libxcb1-dev \ libxkbcommon-dev libgl1-mesa-dev libxrandr-dev libxi-dev libxcursor-dev

🍎 macOS Recommended

Download the Universal installer package — a single .pkg that runs natively on both Intel and Apple Silicon Macs.

  1. Download KinetixInstaller-macos-universal.pkg below.
  2. Open it and follow the installer. Since it isn't notarized yet, right-click the .pkg and choose Open to bypass Gatekeeper's warning.
  3. Once installed, open a terminal and verify with:
kivm version

Build from source instead

Only the Rust toolchain and Xcode Command Line Tools are required — no Homebrew packages needed, and LLVM is not a build dependency of the default build.

  1. Install prerequisites:
xcode-select --install curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  1. Clone and build (produces kivm / kicomp):
git clone https://github.com/MisterY3515/Kinetix.git cd Kinetix cargo build --release -p kinetix-cli -p kinetix-kicomp sudo cp target/release/kivm /usr/local/bin/ kivm version

To also produce a Universal (x86_64 + arm64) build like the official installer, use the provided build script instead of a plain cargo build:

./scripts/build_macos.sh

Future Platforms

📱 Android & iOS Phase 9

Native mobile targets are planned for Phase 9 of the roadmap, including Android (aarch64) via NDK and iOS (arm64) via Metal/LLVM AOT compilation.

🌐 WebAssembly (WASM) Phase 9

WASM compilation target with a capability-sandboxed runtime is planned for Phase 9, enabling Kinetix programs to run in the browser.
